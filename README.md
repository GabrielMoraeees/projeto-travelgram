Uma rede social para amantes por viagens, nele você poderá postar suas recordações de cada viagem e conhecer novas pessoas dentro da plataforma. 
Interface intuitiva e responsiva para diversos dispositivos. (Inicialmente apenas a versão de apresentação do projeto front-end)
Tecnologias utilizadas: HTML5, CSS3, Controle de Versão Git Hub, Figma.
